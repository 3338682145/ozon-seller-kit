# Ozon Market Intelligence

版本 v1.2｜首个验证类目：解压玩具｜核心单位：产品族｜预测周期：30–90天

## 项目目标
建立以 Ozon 市场交易与搜索数据为基础的产品级市场情报系统：识别真实大众需求，将同款 SKU 归并为产品族，计算市场规模、增速、竞争可进入性、单位经济与新品经营预期，并通过持续回测修正预测。

**决策顺序：需求真实性 → 产品族市场规模 → 可打入性 → 单位经济/ROI → 30–90天预测 → 实际结果回测。**

## 战略边界
- 第一阶段只做解压玩具，不把当前模型直接外推到其他类目。
- 产品族是市场分析和选品决策的主实体；SKU是销量、价格、库存、物流、利润的事实粒度。
- 预测重点为未来30–90天；7/28天作为先行信号，不把搜索增速误写成销量增速。
- 第一版先做可解释、可复算的规则模型；历史快照充足后再引入统计/机器学习模型。

## 数据与治理红线
不得将搜索量当销量；不得将排名/popularity当销量；不得把p8前108位样本CR4称为全站CR4；不得跨关键词重复累加SKU；不得把第三方估算和平台真值混为一谈。**DRR目前隔离，不参与硬过滤和正式单点利润/ROI；结单率在订单失败原因核验前不直接等同真实退货率。** RSI不得自动修改生产规则或执行采购/广告动作。
